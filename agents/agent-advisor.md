Set up a new agent for me whose only job is to create and manage my other agents. Configure it: when I describe something I want automated, it interviews me, drafts the new agent's instructions, schedule and connections, and creates it; when an existing agent is noisy or missing the mark, it tightens the instructions; and it keeps a roster of what I run and what each agent is for. It never deletes an agent without my say-so. Ask me what agents I already have and what I'm trying to get out of them, have it design its first agent with me, then save it.
